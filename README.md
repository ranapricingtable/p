# 👑 Rana Design Studio | Luxury Invitation & Event Showcase

An interactive, high-end digital invitation and event design portfolio engineered with seamless ordering workflows, device analytics tracking, and an administrative control panel.

---

## ✨ Key Highlights

* **Interactive Catalog & Services:** Engaging user interface showcasing tailored invitation cards and digital design services.
* **Direct Order Generation:** Streamlined booking flow integrating automated tracking reference IDs (`RANA-2026-XXXX`).
* **Live Visitor Analytics:** Client-side event tracking capturing visitor device categories and checkout conversion status.
* **Secured Admin Control Hub:** Password-protected dashboard to manage orders, update project workflows, and review performance analytics.

---

## 🛠️ Built With

* **Frontend:** HTML5, CSS3 (Modern Glassmorphism & Fluid Layouts), Vanilla JavaScript (ES6+).
* **Backend Architecture:** Node.js, Express.js.
* **Database & Persistence:** SQLite (`better-sqlite3`).
* **Security & Optimization:** Helmet HTTP headers, dynamic rate limiting, CORS configuration.
